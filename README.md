# سوق المنطقة المحلي (تطبيق أندرويد)

تطبيق متجر إلكتروني مجاني مخصص لمنطقة محلية صغيرة، يربط بين **البائعين** و**المشترين** بشكل مباشر مع عرض الأسعار بالدينار العراقي (`د.ع`) وتوفير معلومات التواصل والعنوان لإتمام البيع محليًا.

## أقسام وأدوار التطبيق

### 1. قسم البائعين (Sellers)
* إنشاء حساب بائع وتسجيل الدخول.
* نشر المنتجات عبر نموذج يفرض تعبئة جميع الحقول المطلوبة دون نقص:
  * **اسم المنتج**
  * **القسم** (مثل: إلكترونيات، ملابس، منزل ومطبخ، سيارات ودراجات، أثاث، مستلزمات أطفال، وغيرها)
  * **النوع** (تصنيف فرعي أو نوع المنتج داخل القسم)
  * **الحالة** (`جديد` أو `مستخدم`)
  * **السعر بالدينار العراقي (`د.ع`)**
  * **العنوان** (المنطقة / الحي / نقطة دالة محلية)
  * **رقم الهاتف** (لتواصل المشتري مباشرة)

### 2. قسم المشترين (Buyers)
* إنشاء حساب مشتري وتسجيل الدخول.
* تصفح المتجر عبر **أيقونات الأقسام** والضغط/النقر عليها للوصول السريع للمنتجات.
* عرض تفاصيل المنتج (الاسم، القسم، النوع، الحالة، السعر بالدينار العراقي) مع بيانات البائع (العنوان ورقم الهاتف) للتواصل المباشر.

## خطة البناء المجانية
* **إدارة الكود وبناء APK:** GitHub + GitHub Actions + GitHub Releases.
* **قاعدة البيانات والخدمات السحابية:** خطط مجانية (مثل Firebase Firestore وAuthentication).
